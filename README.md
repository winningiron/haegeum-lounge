# 해금 초견 라운지 (Haegeum Sight-Reading Lounge)

해금 초견 교본 150곡 프로젝트의 **기초 50곡(1~50)**과 **중급·고급 시범 20곡(51~60·101~110)** — 모두 **70곡**을 바로 연습할 수 있는 정적 웹 라운지입니다.

- 기초 1~50 · 중급 51~60 · 고급 101~110 (70곡)
- 각 곡 **7단**, **A4 세로 한 페이지**. 한 줄에 넣는 마디 수는 박자에 따라 다르다.
  - **4/4 → 한 줄 6마디**, **12/8 → 한 줄 5마디**, 그 밖(3/4·2/4·6/8·9/8·5/8·7/8) → 6~8마디
  - 곡마다 **35~56마디** (`tools/pieces.py` 의 `lines` 에 줄별 마디 수를 적는다)
- 음역 **A3~C6** (기초는 A3~F5에서 시작해 A3~C6까지 넓어진다), 조표 **E♭ 33 · A♭ 23 · B♭ 6 · D♭ 6 · F 1 · G♭ 1** (70곡)
- 조표 난이도는 **해금 기준**: 가장 편한 **E♭(♭3)** 에서 시작해 **A♭(♭4) → B♭(♭2)·D♭(♭5) → F(♭1)·G♭(♭6)** 순으로 어려워진다. 기초 50곡은 **E♭ 27 · A♭ 17 · B♭ 3 · D♭ 3** — 1~7번 E♭, 8~13번 A♭, 35번 B♭, 43번 D♭. 중급·고급의 조바꿈도 E♭·A♭·B♭·D♭ 안에서만 움직인다.
- 악보 PNG(2093×2986, A4 세로 비율) + 인쇄용 PDF(A4 세로 1장)

## 연주 도구

악보 모달 아래 줄에서 바로 씁니다.

- **연주** — 첫 마디 예비박(한 마디 메트로놈) 뒤에 전곡을 재생합니다.
  - 모드: `피아노+메트로놈` · `예비박+메트로놈만` · `피아노만`
  - 속도: `0.75×` · `0.85×` · `1.0×`
- **메트로놈** — 장구가 아닌 서양 전자 메트로놈 톤. 마디 첫 박은 높은 소리(1568Hz, 강박),
  복합박자(5/8·7/8·6/8·9/8·12/8)는 악보의 빔 묶음(3+2, 3+2+2)대로 그룹이 바뀌는 박에
  중간 강세(1245Hz)를 주고, 나머지 박은 낮은 소리(1046Hz)로 구분합니다.
- **피아노 가이드** — 단순 합성음이 아니라 **Salamander Grand Piano 실제 그랜드피아노 녹음 샘플**을
  Web Audio 로 재생합니다(곡 음역 A3~C6, 3반음 간격 10개 샘플을 재생 속도로 미세 조정).
  재생 속도에 조율 기준음(A4 442Hz 등)을 함께 반영해, 조율 패널에서 기준을 올리면
  피아노 가이드도 같은 기준으로 올라갑니다.
- **노래방식 커서** — 재생 위치에 맞춰 악보 위 현재 마디를 감싸고, 마디 안을 채우며 지나갑니다.
  악보를 눌러 그 마디부터 시작할 수 있고, 진행 바를 눌러 이동할 수도 있습니다.
  **악보를 처음 열었을 때와 연주 전에는 커서를 그리지 않고**, `▶ 연주`로 재생이 시작될 때 나타납니다.
  재생 중 `■ 정지`를 누르면 멈춘 마디에 그대로 남아 이어서 시작할 위치를 보여 줍니다.
- **곡 이동** — 악보 모달 머리줄(`✕` 옆)의 `‹ 이전 · 2 / 10 · 다음 ›`. 악보 위를 가리는 버튼은 두지 않았고,
  집중 연습 중에는 아래 도구 줄 왼쪽에 같은 버튼이 나옵니다(모달 머리줄이 숨어 있어서).
- **A–B** — 버튼을 두 번 눌러 시작·끝 마디를 잡으면 그 구간만 반복합니다.
  재생 중에 눌러도 **지금 연주 중인 마디**가 A·B로 잡히고, B마디 끝을 넘는 음은 미리 잡지 않아
  반복할 때 B 뒤 소리가 새지 않습니다.
- **음정 체크** — 마이크를 켜면 지금 악보가 요구하는 음과 실제 연주 음정의 차이(센트)를
  실시간으로 보여 주고, 연주가 끝나면 점수와 코멘트(높음/낮음 경향, 흔들린 마디)를 보여 줍니다.
- **집중 연습** — 상단 UI를 숨기고 악보 첫 단부터 화면에 붙여 보여 줍니다. **기다리는 시간 없이 바로**
  연주·메트로놈·A–B·음정 체크를 그대로 쓸 수 있습니다. (첫 단이 잘리지 않도록 `scrollTop` 0)
  브라우저가 허용하면 네이티브 전체 화면까지 함께 들어가고, 끝낼 때 함께 나옵니다.
- **실전 테스트** — 첫 화면의 `🎯 실전 테스트(랜덤 출제)` 또는 악보 모달의 `🎯 실전 테스트`.
  - 출제 범위는 현재 난이도 탭 또는 전체 70곡 중에서 고른다. `다른 곡 뽑기`로 바로 다음 곡을 뽑는다.
  - 진입하면 **30초 읽기 카운트다운**(`30초 동안 악보를 읽으세요`, 건너뛰기·중단 가능).
  - 30초가 끝나면 신호음과 함께 **“시작하세요!”** — 그 뒤로는 피아노·메트로놈 소리도, 커서도 없이
    악보만 보고 연주합니다. 하단에 그 곡의 연주 시간(timeline)을 거꾸로 세는 **`-01:46` 마이너스 스톱워치**가 큽니다.
  - 제한 시간 전에 다 쳤으면 **`다 쳤어요`** 로 바로 끝내고 **실제 소요 시간**과 남은 시간을 보여 줍니다.
  - `00:00`이 되면 종료 신호음과 **“제한 시간 종료”** 안내, `다른 곡 뽑기`·`이 곡 다시`·
    `집중 연습으로 전환`(이 곡을 그대로 집중 연습으로 이어서)·`닫기`. 중간에 `중단`도 된다.
  - 30초 읽기와 스톱워치는 모두 `performance.now()` 기준이라 탭이 잠시 뒤로 가도 시간이 어긋나지 않습니다.
  - 시험 중 `🎤 음정 체크`를 켜 두면 끝났을 때 점수와 코멘트까지 받는다(기본은 조용히 타이머만).
- **조율** — A4 기준을 440~450Hz에서 고르고(기본 442Hz), 그 기준에 맞춘 곡의 으뜸음,
  해금 개방현(중현 G3 · 유현 C4, 완전5도)을 소리로 들을 수 있습니다.
  으뜸음은 늘 가운데 음역(C4~B4)이라 D♭조는 **D♭4(약 277Hz)** 로 들립니다.
- **카드 표기** — 곡 카드에 조표·박자와 함께 템포를 적는데, 곡 중 템포가 바뀌면 전부 적습니다
  (예: `♩ = 80 → 63 → 84 → 72`). 8분의 복합 박자는 점4분음표 박이라 `♩. = 72` 처럼 적습니다.

카드 썸네일은 각 곡 악보의 첫 단을 은은하게 보여 줍니다.

### 데이터 만들기

```bash
cd tools
python3 extract_timeline.py        # 70곡 data/tl/*.json 생성 (악보 PNG 는 읽기만)
```

`extract_timeline.py` 는 `gen_scores.build_piece()` 의 음표·쉼표·붙임줄·장식음·템포·박자에서
연주 타임라인을 만들고, 마디 좌표는 배포된 `scores/NNN.png` 의 오선과 마디줄, 조판 SVG 의
마디 위치를 맞춰 잽니다. 단 첫머리나 박자·조가 바뀌는 마디는 상자 왼쪽 끝을 마디줄이 아니라
첫 음표/쉼표 앞으로 잡아, 커서가 높은음자리표·조표·박자표 위를 지나가지 않게 합니다.
마디줄을 넘는 붙임줄은 길이를 이어 붙이고, 장식음은 본음 직전에 짧게 선행 타격하도록 시간을 잡습니다.

## 악보 제작 방식

`tools/gen_scores.py`가 MusicXML을 만들고, Verovio(Leland, SIL OFL)로 조판한 뒤 resvg_py로 래스터화하고
PyMuPDF로 PDF를 씁니다. 조판 규칙:

- 여백 테두리 없음, 좌상단 번호 박스
- 우상단 `LEE SEUNG CHUL (with AI)` 크레딧
- 하단 `무단 복제 및 배포를 절대 금합니다.`
- 템포는 벡터로 그린 4분음표/점4분음표 + `= BPM`
- 장식음은 1음은 사선 깃발, 2~3음은 16분음표 겹빔(`graceFactor: 0.56` 로 작게 그려
  빔으로 이어도 음두끼리 닿지 않는다)
- 음 간격: `spacingLinear 0.24` · `spacingNonLinear 0.58` — 시가가 길수록 넓게.
  4분:8분 = 1.48, 8분:16분 = 1.42, 점8분:16분 = 1.79 배(70곡 실측 중앙값).
  예전 값(0.55 · 0.35)은 16분·8분·4분이 거의 같은 폭이 되어 시가가 드러나지 않았다.
  `work/spacing_check.py`(비례·역전), `work/collision_check.py`(최소 간격)로 70곡을 점검
- 점8분음표 + 16분음표 짝은 박 경계를 넘어도 한 빔으로 묶음
- 슬러는 **박의 첫 음에서만** 시작한다. 8분음표 빔의 두 번째 음처럼 빔·박 중간에서
  시작하는 슬러는 프레이즈 시작을 잘못 읽게 하므로 만들지 않고, 빔 모양을 정한 뒤
  한 번 더 확인해 위반이 남으면 지운다(`work/check_slur_midbeam.py`). 쉼표를 가로지르는 슬러도 만들지 않는다
- 페이지는 A4 세로(2250×3182 = 2100×2970 의 1.07배, 음표가 그만큼 작아지고 간격이 그만큼 넓어짐),
  줄은 위아래 여백을 같게 두고 고르게 펴고, 마지막 줄도 오른쪽 여백까지 채움
- 박자·조표가 바뀌는 마디 앞에는 겹세로줄
- 곡 중간 조바꿈은 그 마디부터 새 조표로 음을 적고 임시표를 다시 계산한다 (장식음 포함, 조표에 이미 있는 내림표는 겹내림표로 적지 않음)
- 6/8·9/8·12/8 은 점4분음표(3/8) 박마다 리듬 덩어리가 끊기지 않도록 패턴을 검사한다
  (`staff_group_violations`, 예: `[8분+8분쉼표+8분]` 금지)
- `divisions=12` 기준으로 모든 마디 길이를 프로그램으로 검증 (4/4=48, 3/4=36, 2/4=24, 12/8=72, 9/8=54, 6/8=36, 5/8=30, 7/8=42)

다시 만들기:

```bash
cd tools
python make_all.py            # 70곡 전체
python make_all.py 51 101     # 특정 곡만
```

기초 곡의 꾸밈표는 곡별 cfg 로 양을 정한다.

- `grace_p` — 한 마디에 꾸밈음을 붙일 확률 (기초 기본 0.28, 기초 후반 0.28~0.35)
- `mordent_measures` — 농현(~)을 붙일 마디 번호 목록. 그 마디(없으면 3마디 안)의 가장 긴 음에 붙인다
  (기초 곡은 `plain=True` 라 스타카토·악센트는 넣지 않고 농현만 이 목록으로 붙인다)
- `bowing=True` — 프레이즈 첫 음에 당김활(내활). 기초는 36번부터
