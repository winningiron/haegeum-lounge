# 해금 초견 라운지 (Haegeum Sight-Reading Lounge)

해금 초견 교본 150곡 프로젝트의 **기초 50곡(1~50)**과 **중급·고급 시범 30곡(51~60·101~110)**, 그것을 바로 연습할 수 있는 정적 웹 라운지입니다.

- 기초 1~50 · 중급 51~60 · 고급 101~110 (70곡)
- 각 곡 **7단**, **A4 세로 한 페이지**. 한 줄에 넣는 마디 수는 박자에 따라 다르다.
  - **4/4 → 한 줄 6마디**, **12/8 → 한 줄 5마디**, 그 밖(3/4·2/4·6/8·9/8·5/8·7/8) → 6~8마디
  - 곡마다 **35~56마디** (`tools/pieces.py` 의 `lines` 에 줄별 마디 수를 적는다)
- 음역 **A3~C6** (기초는 A3~F5에서 시작해 A3~C6까지 넓어진다), 조표 **E♭ 33 · A♭ 23 · B♭ 6 · D♭ 6 · F 1 · G♭ 1** (70곡)
- 조표 난이도는 **해금 기준**: 가장 편한 **E♭(♭3)** 에서 시작해 **A♭(♭4) → B♭(♭2)·D♭(♭5) → F(♭1)·G♭(♭6)** 순으로 어려워진다. 기초 50곡은 **E♭ 27 · A♭ 17 · B♭ 3 · D♭ 3** — 1~7번 E♭, 8~13번 A♭, 35번 B♭, 43번 D♭. 중급·고급의 조바꿈도 E♭·A♭·B♭·D♭ 안에서만 움직인다.
- 악보 PNG(2093×2986, A4 세로 비율) + 인쇄용 PDF(A4 세로 1장)

## 악보 제작 방식

`tools/gen_scores.py`가 MusicXML을 만들고, Verovio(Leland, SIL OFL)로 조판한 뒤 resvg_py로 래스터화하고
PyMuPDF로 PDF를 씁니다. 조판 규칙:

- 여백 테두리 없음, 좌상단 번호 박스
- 우상단 `LEE SEUNG CHUL (with AI)` 크레딧
- 하단 `무단 복제 및 배포를 절대 금합니다.`
- 템포는 벡터로 그린 4분음표/점4분음표 + `= BPM`
- 장식음은 1음은 사선 깃발, 2~3음은 16분음표 겹빔(`graceFactor: 0.56` 로 작게 그려
  빔으로 이어도 음두끼리 닿지 않는다)
- 음 간격: `spacingLinear 0.24` · `spacingNonLinear 0.58` — 시가가 길수록 넓게.
  4분:8분 = 1.48, 8분:16분 = 1.41, 점8분:16분 = 1.79 배(30곡 실측 중앙값).
  예전 값(0.55 · 0.35)은 16분·8분·4분이 거의 같은 폭이 되어 시가가 드러나지 않았다.
  `work/spacing_check.py`(비례·역전), `work/collision_check.py`(최소 간격)로 70곡을 점검
- 점8분음표 + 16분음표 짝은 박 경계를 넘어도 한 빔으로 묶음
- 페이지는 A4 세로(2250×3182 = 2100×2970 의 1.07배, 음표가 그만큼 작아지고 간격이 그만큼 넓어짐),
  줄은 위아래 여백을 같게 두고 고르게 펴고, 마지막 줄도 오른쪽 여백까지 채움
- 박자·조표가 바뀌는 마디 앞에는 겹세로줄
- 곡 중간 조바꿈은 그 마디부터 새 조표로 음을 적고 임시표를 다시 계산한다 (장식음 포함, 조표에 이미 있는 내림표는 겹내림표로 적지 않음)
- 6/8·9/8·12/8 은 점4분음표(3/8) 박마다 리듬 덩어리가 끊기지 않도록 패턴을 검사한다
  (`staff_group_violations`, 예: `[8분+8분쉼표+8분]` 금지)
- `divisions=12` 기준으로 모든 마디 길이를 프로그램으로 검증 (4/4=48, 3/4=36, 2/4=24, 12/8=72, 9/8=54, 6/8=36, 5/8=30, 7/8=42)

다시 만들기:

```bash
cd tools
python make_all.py            # 70곡 전체
python make_all.py 51 101     # 특정 곡만
```

기초 곡의 꾸밈표는 곡별 cfg 로 양을 정한다.

- `grace_p` — 한 마디에 꾸밈음을 붙일 확률 (기초 기본 0.28, 기초 후반 0.28~0.35)
- `mordent_measures` — 농현(~)을 붙일 마디 번호 목록. 그 마디(없으면 3마디 안)의 가장 긴 음에 붙인다
  (기초 곡은 `plain=True` 라 스타카토·악센트는 넣지 않고 농현만 이 목록으로 붙인다)
- `bowing=True` — 프레이즈 첫 음에 당김활(내활). 기초는 36번부터
